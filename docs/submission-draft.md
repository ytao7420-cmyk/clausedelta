# ClauseDelta contribution

Category: Intelligent Contracts

Title: ClauseDelta — Evidence-Bound Specification Change Attestations

## Description (993/1000 characters)

ClauseDelta is a reusable GenLayer primitive for criterion-local specification migration. Requesters commit SHA-256 hashes of two fixed W3C WCAG versions. Validators independently fetch bytes, preserve the full section-ID index, interpret local duties and compare both entailment directions. A separate check verifies substantive exact-line evidence. Deterministic code derives added, removed, strengthened, weakened, unchanged, incomparable, conflict or unknown; uncertainty cannot create reliance receipts. Consumers bind receipts to the immutable attestation digest and expected outcome.

The adapter supports Parsing, Focus Visible and Focus Not Obscured Minimum. It distinguishes a missing section from a retained but explicitly obsolete requirement. Includes source snapshots, SDK reproducer, negative-path tests and receipt verification. No whole-standard compliance or legal claims. All live-test actors are project-controlled and Studionet only. See docs/validation.md for run status.
